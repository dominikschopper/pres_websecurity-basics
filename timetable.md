# Timetable – one-day training

Approximate schedule, starting 09:00. Shift as needed; the hacking sessions are the
least predictable part, so the afternoon has a buffer slot instead of a fixed AI deck slot.

| Time | Duration | Block |
|---|---|---|
| 09:00–09:30 | 30 min | Intro round + expectations |
| 09:30–10:15 | 45 min | Deck 1 – OWASP & Top 10 |
| 10:15–10:30 | 15 min | Break |
| 10:30–11:15 | 45 min | Deck 1b – Injections (attack scenarios + mitigations) |
| 11:15–11:30 | 15 min | Assign Juice Shop instances |
| 11:30–12:30 | 60 min | Lunch break |
| 12:30–13:00 | 30 min | Demo: happy path + finding the scoreboard |
| 13:00–14:00 | 60 min | Hacking session 1 |
| 14:00–14:30 | 30 min | Interim recap (everyone shows one finding) |
| 14:30–15:45 | 75 min | Deck 2 (CVE/CWE, short) + hacking session 2 |
| 15:45–16:45 | 60 min | Buffer: more hacking **or** Deck 3 (AI), if time/interest allows |
| 16:45–17:00 | 15 min | Closing recap of the day |

Total ≈ 8h incl. breaks.
